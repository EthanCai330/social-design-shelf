# 光标拖尾 Cursor Trail

- **风格**：暗黑奢华 / 流体渐变
- **来源**：用户提供的提示词 · 收录于 2026-11-25
- **适用场景**：品牌站 Hero、创意作品集、暗色落地页

> 原始提示词：CursorTrail：鼠标划过留下一串渐隐轨迹。生成蓝紫色圆点拖尾，依次延迟跟随、缩小淡出，停止后自然消失。

## 行为

光标移动时，在身后留下**一串圆点**。每个点：
- 位置滞后于前一个点（依次延迟跟随）
- 尺寸与不透明度随序号递减
- 停止移动后，尾点继续缓缓缩聚直到消失

不是"一条线"，而是**离散的点序列**——这是它区别于普通尾迹的关键。

## 时长与曲线
- 点阵数量：`12~20` 个
- 每点跟随延迟：`lerp 0.18~0.28`（越靠后越小）
- 单点生命周期：`400~600ms`
- 停止后清空：`800ms` 内全部收缩消失
- 缩放缓动：`ease-out`

## 视觉
- 拖尾颜色：从 `#7B61FF`（紫）过渡到 `#4FA8FF`（蓝），按序号插值
- 首点半径：`6px` → 末点 `1.5px`
- 首点不透明度：`0.55` → 末点 `0.08`
- 混合模式：`mix-blend-mode: screen`，暗底上会自然叠加发光
- 建议加极轻的光晕：`filter: blur(1.5px)`

## 实现要点

```js
// 尾点跟随：每帧把前一个点的位置 lerp 过来
for (let i = 1; i < points.length; i++) {
  points[i].x = lerp(points[i].x, points[i-1].x, 0.35);
  points[i].y = lerp(points[i].y, points[i-1].y, 0.35);
}
```

- 用 `rAF` 驱动，**不要**用 `mousemove` 直接画（会掉帧）
- 点数越多越"黏"，越少越"飘"
- 停止移动后应继续更新，让尾点自然收拢，不要立刻静止

## 细节与反例

- **不要在内容密集的页面用**。拖尾会盖住文字，破坏可读性。
- **不要做成实心大圆**。半透明 + 小半径 + 混色叠加才是"光"的质感。
- **点数不要超过 20**。超过会变成"一坨"，看不出离散感。
- **移动端不要做**。手指自带遮挡，拖尾完全看不见。
- 性能：用 canvas 而非多个 DOM 元素，DOM 版在 60fps 下会明显卡。

## 降级
- `prefers-reduced-motion`：完全不显示拖尾
- 触屏设备（`input: pointer` 不可用）：禁用
- 低端设备：点数减到 8，关闭 `mix-blend-mode`
