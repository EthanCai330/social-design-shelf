# 跟手放大图标排 Finger-Tracking Icon Row

- **风格**：静谧极简
- **来源**：用户提供的提示词 · 收录于 2026-11-25
- **适用场景**：表情选择、评分、心情选择、工具排

## 行为
一排图标，手指按住左右滑动时，指到的图标最大并向上抬起（避免被手指挡住），相邻两个稍大，再往外依次恢复原大小，大小随手指位置连续变化。松手后选中当前图标。

## 时长与曲线
- 跟手：实时，无过渡延迟，由手指 x 坐标连续驱动
- 松手选中：spring，`stiffness 320 / damping 26 / mass 1`（ζ≈0.73），回落到 1.06x
- 未选中图标归位：180ms

## 视觉
- 基础 32px，最大 1.45x（约 46px），邻居 1.22x、1.08x
- 抬起量：最大 16px，与放大同步
- 选中态在松手后加一个 2px 品牌色下划线或光圈

## 降级
`prefers-reduced-motion`：取消连续放大，改为点击选中 + 描边。
必须同时支持键盘方向键与直接点击。

## 细节与反例
- **必须是连续函数**：用高斯或 `1 - min(1, dist/range)` 衰减，不要"进入时就触发一次动画"。
- 抬起（上移）是重点——只放大不上移，图标会被手指完全挡住。
- 移动端抬起方向要朝屏幕上方，而不是朝指尖方向。
- 松手后所有图标必须归位，只有选中的保留轻微放大。
