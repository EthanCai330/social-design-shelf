# 毛玻璃 Glassmorphism

- **风格**：玻璃拟态
- **来源**：用户提供的提示词 · 收录于 2026-11-25
- **适用场景**：弹层、导航栏、卡片、任何"浮在内容之上"的层

> 原始提示词：Glassmorphism：半透明磨砂卡片，背景朦胧、文字清晰。
> `rgba(255,255,255,0.15)` 背景 + `backdrop-filter: blur(16px)` + 1px 半透明白色描边。

## 行为

元素半透明，背景被模糊，但元素内文字保持清晰。
这是**材质**而非动效，无交互，静态即成立。

## 时长与曲线
无。若随滚动或切换出现，过渡 `200~300ms`，`cubic-bezier(0.32,0.72,0,1)`。

## 视觉

**基础配方**
```css
.glass {
  background: rgba(255, 255, 255, 0.15);
  backdrop-filter: blur(16px) saturate(160%);
  -webkit-backdrop-filter: blur(16px) saturate(160%);
  border: 1px solid rgba(255, 255, 255, 0.18);
  border-radius: 16px;
  box-shadow:
    inset 0 1px 0 rgba(255, 255, 255, 0.22),   /* 顶部高光 */
    0 8px 32px rgba(0, 0, 0, 0.12);            /* 落地阴影 */
}
```

**三个必备参数**（缺一个都会"不像玻璃"）：
1. `backdrop-filter: blur()` —— 磨砂
2. **1px 半透明描边** —— 玻璃的厚度
3. **顶部内高光** —— 光线打在玻璃上沿

**`saturate()` 很关键**：`blur()` 会同时降低饱和度和对比度，
加 `saturate(140%~180%)` 能把被模糊掉的背景色彩"补"回来，玻璃才通透。

## 参数速查

| 场景 | blur | 背景透明度 | 备注 |
|---|---|---|---|
| 导航栏 | `20~24px` | `0.7~0.85` | 需保证文字可读 |
| 弹窗 | `16~20px` | `0.12~0.20` | 暗色底上用白色叠加 |
| 卡片 | `12~16px` | `0.10~0.18` | 避免过多玻璃叠玻璃 |
| 暗色主题 | 同上 | `rgba(255,255,255,0.06~0.10)` | 描边降到 `.10` |

## 细节与反例

- **玻璃必须"有东西在动"**。背景是纯色时，`blur` 做不出任何效果，
  这是毛玻璃最常见的失败原因。背景必须有纹理、图像或运动。
- **不要叠超过两层**。玻璃叠玻璃会让上层几乎不透明，失去通透感。
- **`backdrop-filter` 的性能代价很大**。大面积覆盖（如全屏导航）+ 滚动时，
  移动端会明显掉帧。能用雾面纯色替代时优先替代。
- **文字对比度必须单独检查**。玻璃会透出背景，背景深色时白字可能读不清。
  稳妥做法是给文字区再加一层 `rgba(0,0,0,.12)` 遮罩。
- **不要用 `opacity` 实现**。`opacity` 会让子元素一起变透明，文字也会糊。
  必须用 `rgba` 背景 + `backdrop-filter`。

## 降级
- 不支持 `backdrop-filter`（部分老浏览器）：退化为 `rgba(255,255,255,0.85)` 实底，
  并保留描边与内高光，视觉上仍成立
- 低端设备/低电量模式：关闭 `backdrop-filter`，改用较高不透明度的纯色
- `prefers-reduced-transparency`：同上，改为不透明背景
