# 底色进度任务 Liquid Progress Task

- **风格**：静谧极简
- **来源**：用户提供的提示词 · 收录于 2026-11-25
- **适用场景**：清单、习惯打卡、打包清单

## 行为
不另加进度条，组件背景色从左往右填充到完成比例。每勾掉一项，底色平滑向前推进。全部完成时整个组件轻轻闪亮一下。

## 时长与曲线
- 底色推进：400–500ms，`cubic-bezier(0.22,1,0.36,1)`
- 完成闪亮：一次 600ms 的柔和明度脉冲，`scale 1 → 1.01 → 1`，不重复

## 视觉
- 未完成底色：页面底色 +2%（如 #FAF9F7 → #F3F1EC）
- 已填充底色：品牌色降饱和版本，或同色系 8–12% 透明度
- 填充与未填充之间：一条 24px 的短渐变过渡边（不是硬切）
- 文字在填充经过时要换色（深字压浅底、浅字压深底），过渡 320ms

## 降级
`prefers-reduced-motion`：底色直接跳到目标比例，去掉完成闪亮。
必须提供文字进度（如"2/4"），不能只靠底色表达。

## 细节与反例
- **填充边不能硬切**：加一段 24–32px 渐变，像水线，才"高级"。
- 文字换色是这招的隐藏难点：填充线扫过文字时必须同步换色，否则中途完全读不清。
- 完成闪亮只做一次，循环闪会变成廉价"成功动画"。
- 反例：在底色之上再加一条进度条——原提示词的核心就是"不加条"。
