# 磁吸按钮 Magnetic Button

- **风格**：暗黑奢华 / 静谧极简
- **来源**：用户对话中提出 · 收录于 2026-11-25
- **适用场景**：主 CTA、悬浮提交、关键操作入口

## 行为
光标进入按钮周围 120px 半径内时，按钮整体朝光标方向位移。

**位移公式（已在 demo 验证）**：设光标到按钮中心距离为 `d`，触发半径 `R = 120`，最大位移 `A = 12`：

```
k = 1 - d / R          // 连续衰减，中心最强，边界归零
offsetX = (dx / d) * A * k
offsetY = (dy / d) * A * k
```

其中 `dx, dy` 是光标相对按钮中心的方向向量。关键点：**位移随距离衰减，不是随距离增大**。
在 `d → R` 时 `k → 0`，位移连续归零，**没有边界跳变**。`d` 很大时用 `d` 归一化方向，
`k` 取 0，不要出现除零（`d < 1e-6` 时位移为 0）。

> 早期版本这里写反过（`(d / R) * A`），会导致越靠近边界位移越大、到 121px 突然跳回原位。
> 正确写法必是 `1 - d/R`。

按钮内文字产生 2px 反向视差：`textOffset = -buttonOffset * (2 / 12)`，即按位移比例反向，最大值 2px。

按下时 `scale 0.96`。

## 时长与曲线
- 跟手位移：无过渡延迟，由光标位置实时驱动；内部可用 lerp(0.16) 平滑，避免抖动
- 按下：150ms，`cubic-bezier(0.32,0.72,0,1)`
- 离开回弹：spring，`stiffness 260 / damping 20 / mass 1`（ζ≈0.62）

**回弹是刻意设计**：该组合约 8% 过冲，正是"被吸住又弹回"的物理感，符合本交互意图。
注意：跟手位移本身用**上面的贝塞尔曲线**（单调，无过冲），过冲只发生在松手后的 spring 上。
若目标场景要零过冲（如嵌入严肃表单），把 damping 提到 `32` 以上即可。

## 降级
- `prefers-reduced-motion`：禁用磁吸位移，只保留按压缩放
- 触屏（`input: pointer` 不可用）：整体退化为 `active` 态 scale 0.96
- 键盘：聚焦时给 1.5px 焦点环，不参与磁吸

## 视觉
- 底色 `#111111`，文字 `#FAFAFA`
- 圆角 `999px`（胶囊），padding `14px 28px`
- 内高光描边：`box-shadow: inset 0 0 0 1.5px rgba(255,255,255,0.12)`
  （用 inset box-shadow 而非 border，避免影响盒模型；1x 屏会略虚，可在 2x 屏渲染）
- hover 柔光：按钮背后放一个 `60px × 60px` 圆形 `#111` + `filter: blur(22px)`，
  透明度 `0.13 * k` 随感应强度变化，过渡 `350ms ease`

## 变体记录

### 变体 B：固定比例偏移（2026-11-25 收录自用户提示词）

用户另提供一组更"轻"的参数：

> 进入 `100px` 范围时向鼠标方向偏移 `30%`，离开后弹性动画复原。

**这与基准方案的差别必须说清楚，两者不能混用：**

| 维度 | 基准方案 | 变体 B |
|---|---|---|
| 感应半径 | `120px` | **`100px`** |
| 位移量 | `A * (1 - d/R)`，最大 `12px` | **`30%`**（按什么算 30%，见下） |
| 边界行为 | 衰减到 0，连续无跳变 | 取决于 30% 的基准 |
| 回弹 | spring `260/20/1`（ζ≈0.62，约 8% 过冲） | 弹性动画复原 |

**关于"偏移 30%"的歧义**：这个表述有两种读法，实现结果差别很大：

- **读法一（推荐）**：偏移量 = 光标相对按钮中心的位移 × 30%
  ```js
  offsetX = (pointerX - buttonCenterX) * 0.3;
  offsetY = (pointerY - buttonCenterY) * 0.3;
  ```
  这样按钮像"被光标牵着走 30%"，手感柔和，**边界连续**（因为指针离开时按钮跟着回 0）。

- **读法二（有缺陷）**：偏移量 = 按钮尺寸 × 30%，方向朝光标
  这会导致按钮在进入范围瞬间**突然跳一大步**（尺寸的 30% 可能是几十像素），
  且离开时突然弹回——**边界不连续**，正是基准方案要避免的问题。

如果采用变体 B，请用**读法一**。

**取舍**：
- 基准方案强调"精准衰减 + 物理回弹"，适合重要 CTA
- 变体 B 更轻巧，适合次级按钮或图标按钮

## 细节与反例
光标离开用 spring，不要线性归位。最大位移不超过 12px——超过就变成"乱跑"，失去高级感。
触屏设备上禁用磁吸，退化为按压缩放。
