# 形变对话框 Morphing Dialog

- **风格**：玻璃拟态 / 静谧极简
- **来源**：用户对话中提出 · 收录于 2026-11-25
- **适用场景**：列表项详情、图片预览、设置弹层

## 行为
点击卡片，卡片本身原地形变：圆角 12px→24px 连续变化，尺寸从卡片扩张到屏幕 90%，背景从半透明白过渡到不透明。旧内容 120ms 淡出，新内容延迟 100ms 淡入并上浮 8px。关闭反向收缩 + 0.98 过冲。支持下拉关闭。

## 时长与曲线
- 形变总时长：420ms，`cubic-bezier(0.32,0.72,0,1)`（该曲线 y 控制点在 [0,1] 内，**单调无过冲**）
- 关闭：约 220ms，同一曲线
- 下拉阈值：120px

**关于"过冲"**：早期版本写"关闭带 0.98 过冲"，与上面的单调曲线矛盾——纯贝塞尔做不到过冲。
**本条目最终采用：无过冲**，即关闭全程用上面的贝塞尔曲线，平滑收起。
如果你确实想要回弹手感（另一条设计路线，非本条目默认），可改关闭动画为
spring `stiffness 300 / damping 22 / mass 1`（ζ≈0.63，约 8% 过冲），
或 `cubic-bezier(0.34,1.3,0.64,1)`（y 控制点 >1 才会冲）。二选一，不要混用。

## 视觉
- 背景 `#FFFFFF`
- 遮罩：`rgba(0,0,0,0)` → `rgba(0,0,0,0.35)`，与形变同步；`opacity` 动画，不用改 blur
  
## 实现要点（必读）
- **形变方式**：用 FLIP（先 `scale` 缩放再反向补偿 `border-radius`），或直接动画
  `width/height/left/top`。前者性能好但圆角会椭圆畸变，需按缩放比反向修正；
  后者有重排但圆角正确。小卡片扩张场景推荐后者，代码直观。
- **背景起始**：从 `rgba(255,255,255,0.6)` 过渡到 `#FFFFFF`（起始必须有明确 alpha）。
- **blur 的性能坑**：`backdrop-filter: blur(0→6px)` 在移动端逐帧改模糊极易掉帧。
  改用固定 `blur(6px)` + 遮罩 `opacity` 0→1，视觉几乎等价、性能好得多。
- **新内容淡入时长**：200ms（旧内容 120ms 淡出，间隔 20ms 属正常交叠，不违背"动画不叠加"，
  因为它发生在形变之后而非同时）。

## 手势状态机
- 下拉跟手：位移 1:1，超过 120px 后加橡皮筋阻尼（`offset = 120 + (d-120)*0.35`）
- 未达阈值松手：回弹 260ms，`cubic-bezier(0.32,0.72,0,1)`
- 快速轻扫：若速度 > 0.5px/ms，即使未达阈值也判定关闭（速度阈值优先于距离阈值）

## 降级
`prefers-reduced-motion`：跳过形变，直接淡入 150ms。
不支持 backdrop-filter：遮罩用纯色 `rgba(0,0,0,.4)`。

## 细节与反例
核心是"不消失再弹出"。如果卡片先缩小再弹窗，就失去了空间连续性。打开慢、关闭快。
