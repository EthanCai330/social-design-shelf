# 新拟态 Neumorphism

- **风格**：静谧极简
- **来源**：用户提供的提示词 · 收录于 2026-11-25
- **适用场景**：轻量工具、音乐播放器、车载控制

> 原始提示词：Neumorphism：同色表面，用柔和阴影塑造凸起与凹陷。按钮与背景同色，左上浅色右下深色双阴影表现凸起，按下切内阴影。

## 行为

元素与背景**完全同色**，仅靠阴影区分凹凸：
- **凸起**：左上浅色高光 + 右下深色阴影
- **凹陷/按下**：切换为 `inset` 内阴影，方向相反
- 视觉上像是"从同一块材料上压出来/压进去"

## 时长与曲线
- 按下切换：`150ms`，`ease-out`
- 不做弹跳或缩放——新拟态的特点是"没有多余动作"

## 视觉

**基础参数**
```css
.nm-surface {
  background: #E0E5EC;                 /* 底色 */
}
.nm-raised {
  background: #E0E5EC;
  border-radius: 16px;
  box-shadow:
    6px 6px 12px #B8BEC7,              /* 右下深 */
    -6px -6px 12px #FFFFFF;            /* 左上浅 */
}
.nm-pressed {
  box-shadow:
    inset 6px 6px 12px #B8BEC7,
    inset -6px -6px 12px #FFFFFF;
}
```

**关键比例**：阴影距离 : 模糊半径 ≈ `1 : 2`（示例是 6px 偏移、12px 模糊）。
阴影颜色：深色 = 底色降明度约 `12%`，浅色 = 底色提明度至接近纯白。

## 细节与反例

- **底色不能纯白**。纯白底上没有"更亮的高光"可用，效果直接失效。底色要选中灰（明度 85~90%）。
- **对比度是新拟态最大的缺陷**。同色设计天然可访问性差，**文字必须够深**。
  重要按钮不要只用新拟态，必须补文字或描边。
- **不要和扁平设计混用**。新拟态是一个完整语言，混入扁平按钮会显得脏。
- **阴影不要偏色**。深色阴影建议直接用低饱和同类色（如 `#B8BEC7`），
  用纯黑 `rgba(0,0,0,.3)` 会显得"脏"。
- 这个风格在 2020 年前后流行过，现在用要克制：**只用于少量次要控件**，不要整页都是。

## 无障碍要点（重要）

新拟态的凹陷/凸起**几乎不可被色盲、低视力、强光下的用户分辨**。
必须保证：
- 所有可交互元素有文字标签，不靠形状传达功能
- `:focus-visible` 用明显的描边（不能也只靠阴影）
- 对比度按 WCAG AA：正文 ≥ 4.5:1

## 降级
- `prefers-reduced-motion`：按压阴影切换改为即时（无过渡），本来也无动画
- 高对比度模式：自动加 1px 描边，保证边界可见
- 深色主题：深色底用更亮的浅阴影（`#2A2E35`），不要照搬浅色参数
